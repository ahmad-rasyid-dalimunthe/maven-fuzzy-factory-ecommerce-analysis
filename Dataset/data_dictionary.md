# Data Dictionary

This document describes the key fields used throughout the analysis.

---

# website_sessions

| Column | Data Type | Description |
|---------|-----------|-------------|
| website_session_id | INTEGER | Unique identifier for each website session. |
| created_at | TIMESTAMP | Session start timestamp. |
| user_id | INTEGER | Unique customer identifier. |
| is_repeat_session | INTEGER | Indicates whether the visitor is new (0) or returning (1). |
| utm_source | STRING | Marketing traffic source. |
| utm_campaign | STRING | Marketing campaign name. |
| utm_content | STRING | Marketing content variation. |
| device_type | STRING | Visitor device (Desktop or Mobile). |
| http_referer | STRING | Referring website URL. |

---

# website_pageviews

| Column | Data Type | Description |
|---------|-----------|-------------|
| website_pageview_id | INTEGER | Unique pageview identifier. |
| created_at | TIMESTAMP | Pageview timestamp. |
| website_session_id | INTEGER | Associated website session. |
| pageview_url | STRING | URL visited during the session. |

---

# orders

| Column | Data Type | Description |
|---------|-----------|-------------|
| order_id | INTEGER | Unique order identifier. |
| created_at | TIMESTAMP | Order creation timestamp. |
| website_session_id | INTEGER | Website session that generated the order. |
| user_id | INTEGER | Customer identifier. |
| primary_product_id | INTEGER | Primary product purchased. |
| items_purchased | INTEGER | Number of purchased items. |
| price_usd | FLOAT | Total order revenue (USD). |
| cogs_usd | FLOAT | Total cost of goods sold (USD). |

---

# order_items

| Column | Data Type | Description |
|---------|-----------|-------------|
| order_item_id | INTEGER | Unique purchased item identifier. |
| created_at | TIMESTAMP | Purchase timestamp. |
| order_id | INTEGER | Associated order. |
| product_id | INTEGER | Purchased product. |
| is_primary_item | INTEGER | Indicates whether the item is the primary purchased product. |
| price_usd | FLOAT | Revenue generated by the item. |
| cogs_usd | FLOAT | Cost of goods sold for the item. |

---

# order_item_refunds

| Column | Data Type | Description |
|---------|-----------|-------------|
| order_item_refund_id | INTEGER | Unique refund identifier. |
| created_at | TIMESTAMP | Refund timestamp. |
| order_item_id | INTEGER | Refunded order item. |
| order_id | INTEGER | Related order. |
| refund_amount_usd | FLOAT | Refund amount in USD. |

---

# products

| Column | Data Type | Description |
|---------|-----------|-------------|
| product_id | INTEGER | Product identifier. |
| created_at | TIMESTAMP | Product launch date. |
| product_name | STRING | Product name. |

---

# Derived Fields

The following fields were created during the transformation process and are not part of the original dataset.

| Field | Description |
|--------|-------------|
| acquisition_source | Standardized traffic source derived from `utm_source` and `http_referer`. |
| gross_profit | Revenue minus Cost of Goods Sold (COGS). |
| refund_flag | Indicates whether an order item has been refunded. |
| net_revenue_after_refund | Revenue after deducting refund amount. |
| gross_profit_after_refund | Gross profit after deducting refunds. |
| product_purchased | Indicates whether the viewed product was ultimately purchased within the same session. |

---

# Notes

- Monetary values are reported in **USD**.
- Dates are stored as **UTC timestamps**.
- Product-level checkout attribution is unavailable because Cart, Shipping, and Billing pageviews do not contain product identifiers.
- Product purchases are confirmed using the `order_items` table.
