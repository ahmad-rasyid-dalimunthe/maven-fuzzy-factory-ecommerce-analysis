# SQL Scripts

This folder contains all SQL scripts used throughout the project.

## Workflow

1. Data Understanding
2. Exploratory Data Analysis (EDA)
3. Data Cleaning
4. Data Mart Development
5. Dashboard Data Sources

## SQL Files

| File | Purpose |
|------|---------|
| 01_data_understanding.sql | Initial inspection of raw tables and data quality |
| 02_exploratory_data_analysis.sql | Business exploration and hypothesis generation |
| 03_data_cleaning.sql | Data standardization and validation |
| 04_mart_dashboard.sql | Executive dashboard data mart |
| 05_mart_acquisition_product_funnel.sql | Acquisition and product funnel data mart |
| 06_mart_refund.sql | Product profitability and refund mart |

All scripts were executed in Google BigQuery.
